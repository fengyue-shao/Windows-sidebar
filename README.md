# Windows Sidebar

使用 Qt/QML 和 C++20 编写的 Windows 侧边栏。

## 使用

- 点击屏幕边缘的把手可展开或收起侧边栏；应用会记住展开状态、当前页面和模块开关。
- `Ctrl+Space`：展开或收起侧边栏。
- `Ctrl+1` / `Ctrl+2` / `Ctrl+3` / `Ctrl+4`：打开概览、监控、通知或专注页面。
- `Ctrl+Q`：退出应用。
- 底部设置面板可切换主题、显示器、停靠方向和信息模块，也可恢复默认布局。
- 面板支持自动隐藏、紧凑布局、360–560 像素宽度和透明度调节。
- 内置专注计时器，提供 5/25/50 分钟节奏、暂停恢复和完成次数统计。
- 点击顶部时间栏可打开月历、切换月份并快速回到今天。
- 概览页可直接调节 Windows 主音量、切换静音，并显示笔记本电池与充电状态。
- 控制中心卡片会在当前布局中展开，可直接调节声音、主题、透明度、宽度、布局与停靠行为，并查看联网和实时流量状态。
- 声音控制可枚举当前音频会话，为浏览器、播放器和游戏分别调节音量或静音。
- 剪贴板页面读取 Windows 系统历史，可预览文本与图片，点击恢复原始内容，并支持应用内置顶和单项删除；若系统提供文件列表格式也会优先显示（Windows 标准历史通常不会保存资源管理器复制的文件项）。
- 网络面板可直接扫描附近 Wi-Fi、查看信号和安全状态，并连接已保存、开放或常见 WPA2-PSK 网络，无需跳转到系统设置。
- 蓝牙面板可扫描经典蓝牙与 BLE 设备，显示已连接/已配对状态，并直接完成配对或取消配对；具体设备服务由 Windows 自动连接。

## Windows 通知权限

Windows 通知监听依赖应用包身份。直接运行构建目录中的
`appqt_rainmeter.exe` 无法获得该身份。

生成已签名的开发 MSIX：

```powershell
cmake --build <构建目录> --target package_msix
```

安装 MSIX：

```powershell
cmake --build <构建目录> --target install_msix
```

首次安装时需要接受 Windows 的本地开发证书安全提示。安装完成后请从
“开始”菜单启动 **Windows Sidebar**，并在首次启动时允许通知访问。
