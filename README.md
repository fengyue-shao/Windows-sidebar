# Windows Sidebar

Windows x64 上的 Qt/QML 桌面控制栏。此仓库只包含主应用、通用插件管理接口及主体测试，不包含任何具体插件实现。

当前为 **2026-10-16 主体精简源码**：主版本 `0.8.2.0`，运行标识 `0.8.2.0-preview`。已安装的同号应用不等于本工作区；自由卡片、多版本插件选择等源码增量尚未作为新安装版发布。用户已授权合并到主分支并在静态检查通过后推送；具体记录见 [审核与提交说明](docs/REVIEW.md)。本次不重新安装或变更软件版本。

## 构建与验证

需要 Windows 10 2004+、MSVC x64/C++20、Windows SDK 与 Qt 6.8+ MSVC x64 Kit；测试额外使用 Qt Test。不自动下载依赖，不依赖终端插件。

```powershell
# 显式选择本机 Qt Kit；默认只构建，产物在仓库外同级 build-host。
.\scripts\build.ps1 -QtBin 'D:\Qt\6.9.3\msvc2022_64\bin'

# 构建主体及安全回归并执行 CTest，不操作真实 Wi-Fi/蓝牙/USB。
.\scripts\build.ps1 -QtBin 'D:\Qt\6.9.3\msvc2022_64\bin' -Test
```

这些路径只是本机示例。运行可视预览、打包签名和安装是分开的显式步骤，见构建说明。直接 EXE 预览不能验收依赖 MSIX 身份的通知/OCR/热点；自动测试也不证明全部实机功能稳定。

## 功能范围

保留顶部下拉栏、系统监控、音频/麦克风/媒体、Wi-Fi/蓝牙、通知、剪贴板/OCR、网络详情/热点、专注/保持唤醒、USB 安全弹出、灵动岛以及工具箱通用插件管理。自由桌面卡片仍为可选开发预览，不把它误报为所有页面的新默认布局。

具体插件由用户另外导入可信本地包，独立进程运行；主体只解析版本化 JSON 展示数据，不执行插件提供的 QML、DLL 或任意命令。终端插件的 `0.8.3.1` 不属于本主体版本。
