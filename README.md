# Windows Sidebar

使用 **C++20、Qt 6 与 QML** 构建的 Windows 桌面控制应用。通过顶部悬停唤出的控制栏，集中查看系统状态、控制音频与设备、处理通知和剪贴板，并以灵动岛汇总活动与提醒。

项目已从早期侧边监控栏演进为桌面控制应用与通用插件宿主，保留 Windows Sidebar 名称。当前仓库包含主应用、通用插件管理接口及主体测试；具体插件独立维护。

## 主要功能

| 方向 | 能力 |
| --- | --- |
| 系统状态 | CPU、内存、GPU、网络速度、磁盘容量 |
| 音频与媒体 | 主音量、应用混音、输出设备、麦克风、媒体会话与封面、动态频谱 |
| 网络与设备 | Wi-Fi、蓝牙、网络详情、移动热点、USB 安全弹出 |
| 日常工具 | 通知分组与筛选、剪贴板历史、图片 OCR、专注计时、保持唤醒 |
| 桌面交互 | 主题与模块设置、灵动岛活动 / 提醒、可选自由卡片预览 |
| 通用插件 | 本地导入、完整性校验、显式信任、版本选择、启停及状态 / 结果展示 |

功能可用性受 Windows 授权、包身份和设备支持影响。通知、OCR、热点等能力需在相应 MSIX 环境中验收；直接运行 EXE 和自动回归不能覆盖全部实机场景。

## 开始构建

准备 Windows x64、MSVC C++20 工具链、Windows SDK、CMake 3.21+ 和 **Qt 6.8+ MSVC x64** 套件；测试另需 Qt Test。在仓库根目录执行，并将示例 Qt 路径替换为本机安装路径：

```powershell
# 默认只配置和构建；产物位于仓库外同级 build-host。
.\scripts\build.ps1 -QtBin 'D:\Qt\6.9.3\msvc2022_64\bin'

# 构建主体与隔离回归并执行 CTest。
.\scripts\build.ps1 -QtBin 'D:\Qt\6.9.3\msvc2022_64\bin' -Test

# 显式部署 Release Qt 运行库，供本地 EXE 预览。
.\scripts\build.ps1 -QtBin 'D:\Qt\6.9.3\msvc2022_64\bin' -Test -Deploy
```

构建入口不会自动安装应用或运行真实设备操作。Visual Studio 生成器的预览程序通常位于 `..\build-host\Release\appqt_rainmeter.exe`，实际位置以脚本输出为准。手动运行前先完成 `-Deploy`；依赖、缓存保护、Debug、MSIX 打包与安装步骤见 [构建与测试](docs/BUILD.md)。

自由桌面卡片可在已部署的 EXE 上使用 `--native-card-preview --preview-cards` 预览。它仍为可选开发功能；具体覆盖范围和布局文件隔离方法见 [自由桌面卡片](docs/FEATURES.md#自由桌面卡片可选开发预览)。

## 插件与 Agent 方向

具体插件由用户导入可信本地包，在独立进程中运行。主体校验包内容，并通过固定 JSON 消息接收状态、提醒与任务结果；不执行插件提供的 QML、DLL 或任意命令。独立进程不是安全沙盒，清单中的权限声明也不等于系统权限隔离。

未来 Agent 接入应建立在明确的能力、权限与结果校验边界之上。内部 QObject 接口目前只供可信内置 QML 使用，尚未形成公共 Agent SDK。现有包格式、进程生命周期和消息约束见 [架构与插件接口](docs/ARCHITECTURE.md)。
