# 灵动岛动效与岛内交互

## 已确认设计

保持顶部栏中央黑色胶囊，不挤占时间、联网、音量、电量及设置。借鉴移动端紧凑/展开层级，但采用鼠标交互：单击灵动岛展开/收起岛内控制，双击继续展开/收起主卡片；来源跳转改为展开后的明确按钮。展开区与胶囊是同一个表面，不另建弹窗。

参考：[Apple Live Activities](https://developer.apple.com/design/human-interface-guidelines/live-activities)、[Design dynamic Live Activities](https://developer.apple.com/videos/play/wwdc2023/10194/)。这里只借鉴状态层级与聚焦当前活动，不复制移动端触摸操作。

| 动效 | 实现规则 |
| --- | --- |
| 宽度形变 | 280 ms OutCubic，连续改目标由当前尺寸继续，不弹跳越界 |
| 高度形变 | 240 ms OutCubic，展开向下覆盖，不移动左右小组件 |
| 来源/任务类型切换 | 180 ms 内容淡入；来源、类型、事件模式或语气改变才触发 |
| 计时/电平/频谱更新 | 不重新入场，不使用伪造进度或随机频谱 |
| 减少动画 | 只读 SPI_GETCLIENTAREAANIMATION，系统关闭时立即完成形变、取消淡入；不修改系统偏好 |
| 命中区域 | 每次实际宽、高、y 改变同步原生 mask；背景消耗鼠标/滚轮，防止覆盖区点击下层导航 |

## 岛内功能

- 媒体：上一首、播放/暂停、下一首；按钮根据当前会话 Controls 能力开启，执行线程重新核验会话 ID 与能力，拒绝过期控制。
- 专注：暂停/恢复；新 paused 属性区分未开始与刚启动即暂停。
- 音频输入：默认麦克风静音/解除静音，以及 Windows 输入设备设置入口；不切换隐私权限、不启用录音。
- OCR：停止识别等待，提示取消不保证底层操作撤回。
- 保持唤醒：停止并释放本应用请求；测试依然只模拟。
- 完成/失败提醒：打开来源查看真实状态；关闭提醒不取消任务、不删除通知。
- 插件任务：暂只提供来源入口，专属控制必须通过后续独立适配接口，不在核心硬编码终端动作。

用户确认暂停媒体优先级 8、暂停专注优先级 5；均低于所有运行任务，高优先级活动/提醒仍可取代它们。当前来源变化时关闭旧控制区，防止把旧按钮带到新任务。快捷控制只按用户点击执行，回归不调整真实设备。

Windows 依据：[媒体 Controls 能力](https://learn.microsoft.com/en-us/uwp/api/windows.media.control.globalsystemmediatransportcontrolssessionplaybackcontrols?view=winrt-26100)、[客户端动画偏好](https://learn.microsoft.com/en-us/windows/win32/winauto/client-area-animation)。

## 已发现的插件耦合（下一阶段必须移除）

主程序 main.cpp 直接构造 TerminalManager、注册 TerminalCanvas 并暴露全局 terminalManager；CMake 主目标编译终端 Manager/Screen/Canvas，强制依赖 Runner 和插件资源；build-msix.ps1 强制要求 Runner 并把插件目录捆绑入主包；Main.qml 按 terminal 路由硬编码具体插件 ID。当前 Loader 继承宿主上下文，权限仍仅声明。

用户确认：改为独立可选插件包、首版仅可信本地插件。移出核心的应包括专属 C++/QML/Runner/资源/生命周期和数据，宿主仅提供版本化通用适配、来源路由、主题令牌及限定插件命名空间的灵动岛接口。不要用简单改名或把全局 terminalManager 包一层假装完成隔离。该阶段尚未实施，不宣称已经满足。
