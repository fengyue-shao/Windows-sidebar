# 灵动岛场景 UI 第一版

2026-10-01，依据本地 SVG 审核稿实现。Figma MCP Starter 额度耗尽后，经用户批准改用本地设计源；未更改旧设计页面，未提交或推送远程仓库。

## 实现

- 保留顶部中央黑色胶囊及 64×24、344×52、420×64 DIP 尺寸，单击打开来源，双击展开/收起。
- 输入：绿色图标、应用名，多应用显示人数。真实电平柱来自默认输入端点，只是该端点的峰值，不代表每个应用或其他输入设备的音量；不创建录音流。
- 媒体：真实会话封面及曲名，封面不可用回退图标；没有时间线就不显示进度。2026-10-01 经用户要求扩展频谱采集条件：开启 FFT、媒体模块启用、会话播放且窗口可见时，只要媒体卡片或媒体灵动岛可见就分析。因此精简顶部栏和 IslandOnly 均可显示，不必展开卡片；完全隐藏、暂停、关闭 FFT、关闭媒体模块，或两处都不可见时停止并清空。两处共用一个采集器，不新增录音、存储或上传。
- 专注：紫色，独立倒计时及进度；完成事件为绿色确认状态。
- 通知：仅应用名，无私密正文。角标表示等待事件数量，不含当前展示事件，持续活动显示时则包括所有等待事件。
- 终端：运行中用不定进度三点提示；完成绿色、失败红色，展示结构化退出码及实际耗时，不显示命令和输出。
- 插件展示字段新增 `kind`、`tone`、`detailText`、`applicationCount`，白名单校验、长度与数值限制；原插件无字段时按 route 回退。未新增任意图片 URL 或执行接口。

## 不变的边界

持续活动优先级、事件缓冲与去重、隐藏时 IslandOnly 唤出规则保持原样。完全隐藏后不会仅为频谱自动保持窗口可见。未改变媒体卡片本身布局，也未安装或覆盖正式 MSIX。图稿中的虚构封面、波形、任务和应用名不作为真实数据接入。频谱仍是默认输出端点的系统混音，不承诺选定媒体应用的专属频谱。
