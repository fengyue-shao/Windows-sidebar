# Windows Sidebar 0.8.1.3 · 本地审核版

日期：2026-10-02。分支 `codex-do`，整合当前工作区的基础功能、稳定性、灵动岛与终端插件改动。应用内版本标识 `0.8.1.3-preview`，MSIX 身份版本 `0.8.1.3`，内置终端插件同步为 `0.8.1.3`。不推送远程，不将模拟测试替代人工验收。

## 更新范围

- 稳定性：系统异步查询的单一等待、超时、取消和关闭边界；USB 弹出保留 Windows 拒绝原因，不强制解除占用；网络详情查询状态和最近更新时间。
- 基础功能：专注单调计时与暂停恢复、保持唤醒释放失败重试、OCR 完成通知、热点及 USB 结构化结果。
- 灵动岛：基础功能来源接入、分级缓冲提醒、关闭提醒不取消任务、来源卡片定位；终端耗时及命令/会话结果事件。
- 终端插件：ConPTY / 兼容模式选择、VT 有界字符网格、固定列绘制、原生按键/IME、辅助补全预览与只插入草稿、复制/多行粘贴确认、会话控制、真实外部退出码及独立轮转日志。
- 构建：每次构建同步插件资产，避免仅修改插件 QML 后运行目录仍是旧版本；新增隔离核心、终端与离屏 UI 测试。

## 用户检查清单

1. 主界面隐藏/展开、设置和卡片命中，灵动岛提醒关闭及卡片跳转。
2. 网络详情、专注暂停/恢复、OCR / 热点 / USB 的状态和提示；USB 被占用时应明确报告原因，不强行弹出。
3. 终端选择兼容模式，检查中文输出、退出码、补全预览、取消和重置。
4. 原生模式的实际中文输入法、Tab 补全、光标及尺寸同步；默认 PowerShell 7 的 PSReadLine 发布者信任提示必须由用户自行决定，应用不得代替确认或修改信任策略。
5. 不同 DPI / 多屏、真实通知授权、设备热插拔及长期运行仍需专项验收。

终端仍不是权限隔离的安全沙盒；VT 并非完整 xterm，复杂字素、鼠标报告和历史列宽重排没有全部完成。原生只能准确报告会话退出，不能推测任意 REPL 命令完成。
