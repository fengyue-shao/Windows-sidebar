## 本轮实现

- 网络详情提供查询中状态、最近查询时间，防止重复刷新；保留上轮后台查询改动。
- 专注计时使用 GetTickCount64 单调时间，而非可调整的系统日期时间；完成后重启及时通知剩余时间变化。模拟测试不读取/写入真实专注设置。
- 保持唤醒区分手动停止、自然到期、释放失败重试；成功释放后才发送一次到期信号。
- OCR 提供完成信号，灵动岛只显示完成提示，不显示识别正文。空白图或失败显示中性“识别已结束”，不冒充识别成功。
- USB 安全弹出提供结构化成功/失败结果，避免靠中文提示前缀判断结果；灵动岛仅提示 Windows 是否接受请求，成功仍需确认设备消失。
- 热点操作结束进入提醒队列；不将“操作结束”误报为“操作成功”。
- 灵动岛短暂提醒提供独立关闭按钮、剩余显示时间条和卡片定位；关闭只结束当前提醒，不取消任务、不删除通知。
- 卡片跳转涵盖 OCR 剪贴板，以及监控中的热点、USB、保持唤醒、网络详情。

## 优先级

| 类型 | 优先级 | 行为 |
| --- | --- | --- |
| 保持唤醒 | 10 | 持续活动，剩余时间及进度 |
| OCR 处理中 | 15 | 持续活动，不上传、不暴露正文 |
| 专注 | 20 | 持续活动 |
| 媒体 | 40 | 持续活动，保留未展开时的频谱 |
| 音频输入 | 60 | 持续活动，保留应用来源识别 |
| OCR 完成 | 75 | 短暂提醒 |
| 新通知 / 热点操作结束 | 80 | 短暂提醒 |
| USB 请求被接受 | 85 | 短暂提醒 |
| 专注完成 / 保持唤醒到期 | 90 | 短暂提醒 |
| USB 请求未完成 | 95 | 高优先级提醒，点击查看原因 |

持续活动仍只展示当前最高优先级的一项，相同优先级保持原顺序。正常消息不频繁抢占；当前提醒至少展示 1.2 秒后，95+ 且更高优先级的消息才可抢占。队列总容量 16（包括正在显示的提醒）；满载时更高优先级消息可替换尚未显示的最低优先级消息，不能直接丢掉正在显示的消息。过期消息丢弃；同一键合并，不延长原时限。已显示/关闭的同键消息有 15 秒冷却。

## 验证与验收边界

提供独立 `sidebar-island-core-test`，只使用模拟时钟与模拟电源请求，不启动 CaptureUsageMonitor 或其他硬件观察器，覆盖优先级、FIFO、合并、冷却、队列满时紧急消息准入、抢占后准确续显、关闭恢复、保持唤醒失败重试与一次性到期，以及专注暂停/恢复/完成。

提供 `sidebar-island-ui-test`，只加载 TopIslandHost 和模拟上下文，以软件离屏渲染生成六种提醒预览，并通过测试窗口内事件验证关闭不触发详情导航。不是完整主应用或真实桌面测试。

主应用编译、模拟测试与离屏 UI 测试结果以本轮实际执行结果为准；完整卡片定位、不同屏幕/DPI、真实系统接口及媒体频谱仍需驱动更新结束后验收。没有运行真实电源、热点、无线切换、USB 弹出或麦克风捕获测试，安装版暂不替换。
