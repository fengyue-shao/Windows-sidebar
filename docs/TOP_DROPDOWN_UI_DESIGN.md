# 顶部下拉卡片 UI：可行性与审核计划

日期：2026-10-01。状态：用户已认可初版 UI 稿，正在验证 0.8.1.0-preview；参见 [实现与验证记录](TOP_DROPDOWN_PREVIEW.md)。下面保留原始设计与验收约束。

## 目标

将左右侧边栏改为顶部唤出的下拉界面。原框架只作为布局、裁剪与窗口边界约束，不绘制一整块背景；顶部栏及具体卡片各自绘制表面，间隙显示桌面。

## 交互状态

| 状态 | 显示 | 进入方式 | 退出方式 |
| --- | --- | --- | --- |
| Hidden | 不显示顶部栏或卡片 | 启动默认、显式隐藏、离开后延时 | 鼠标停留顶部触发区，或全局快捷键，仅到 Bar |
| Bar | 精简顶部栏：时间、状态摘要、展开按钮 | 边缘/快捷键唤出 | 离开后延时隐藏；手动点击展开到 Cards |
| Cards | 顶部栏及当前类别的具体卡片 | 仅用户主动点击展开 | 收起按钮/Esc 回到 Bar；明确隐藏操作到 Hidden |

悬停不展开卡片。手动隐藏优先于自动隐藏，鼠标必须先离开触发区才能再次悬停唤出。设置、日历、菜单、插件内容均计入交互区域；输入、拖动、对话框打开时暂停自动隐藏。

## 代码可行性

结论：可行，但属于壳层重构，不是移动一个 Rectangle。

- `qml/Main.qml` 已是无边框、置顶、透明的 Qt Window；可复用。当前全屏高度、左右停靠和宽度动画需改为顶部锚定、状态对应窗口尺寸与垂直动画。
- `src/displaymanager.cpp` 已提供所选屏幕的坐标与尺寸；需扩展顶部定位、安全可用区域及 DPI/多显示器边界处理。
- `qml/Sidebar.qml` 的全背景与纵向 StackLayout 要拆为透明约束根、精简顶部栏和卡片容器；现有业务卡片及 C++ 服务继续复用。
- 当前 `uiSettings.expanded` 布尔值要迁移到三态控制器，并兼容旧配置。顶部栏显示状态与卡片展开状态不可继续混为一个值。
- 当前 QML Shortcut 不是系统全局唤出。实现阶段需添加 Windows RegisterHotKey / WM_HOTKEY，冲突时允许配置并反馈失败。
- 透明像素不会自动让点击穿过原生窗口。实现需按状态缩小原生窗口，并验证卡片间透明区域的输入区域/命中测试，不能仅靠 opacity，也不能让可见按钮点击到桌面。
- 插件仍由工具箱管理，插件 UI 加载在受约束的内容区；不允许插件覆盖唤出栏或扩大输入区域。

## 初版视觉提案

- 顶部居中，窄胶囊栏；以时间、网络、声音和电量摘要为主，右侧明确的“展开”操作。
- 展开后显示分类导航与独立卡片，不加覆盖整片桌面的遮罩或大背景。
- 分类保持监控、通知、专注、剪贴板、工具箱；声音/网络作为监控中的具体控制卡片。AI 不占核心导航。
- 保留原主题色。审核稿使用 Noto Sans SC：Figma 环境未提供 Windows 默认字体，因此字体细节不作为最终像素规格，应用仍沿用系统字体。
- 审核稿中的数据是视觉示例，不代表新增能力已经实现。

- 三态桌面示意节点：Hidden `5:42`，Bar `5:47`，Cards `5:56`。桌面示意背景不是应用整块背景，卡片间隙在实际应用中显示用户桌面。

## 实现阶段验收（待审核后开展）

1. 全局快捷键冲突、边缘停留防误触、手动隐藏防立即重开。
2. 多显示器、负坐标、缩放、分辨率变化、全屏应用、顶部任务栏。
3. 卡片/间隙命中测试，弹出控件不丢焦点、不误自动隐藏、不点击穿透。
4. 插件启停与页面加载、设置入口、键盘导航、长内容滚动（隐藏视觉滚动条，不取消滚动）。
5. 透明约束窗口不阻挡无关桌面区域；动画不闪烁，功能和设置迁移可回退。
