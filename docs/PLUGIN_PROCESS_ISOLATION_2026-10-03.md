# 独立进程插件：实施约束与接口第一版

用户已选择终端 UI 和后端全部独立进程，不采用宿主进程加载 Qt DLL。本文是实施规格与进度记录，不代表拆分已经完成。

## 边界

- 主应用不编译终端画布、屏幕、管理器、Runner，也不加载插件 QML；可选包拥有专属代码、资源、日志及数据。
- 工具箱是唯一插件管理 GUI。首版只接纳用户明确信任的本地包，不默认执行扫描发现的程序。
- 宿主提供通用生命周期与版本化数据协议，不向子进程暴露 QML 根上下文、音量/网络等核心对象、任意命令执行接口。
- 进程隔离降低插件崩溃对宿主的影响，但同用户进程不是安全沙盒。权限清单不等于 Windows 强制权限控制。
- 用户已确认首版独立窗口，由工具箱启动和管理，不做跨进程窗口嵌入。保留原生焦点与输入法，不把外进程窗口 SetParent 到主应用卡片中。

## 通信协议 v1

使用 QLocalServer/QLocalSocket，不把终端 stdout 当作控制协议。宿主每次启动生成随机管道名和随机 token；服务器在 listen 前设置 UserAccessOption。Qt 官方依据：[QLocalServer](https://doc.qt.io/qt-6/qlocalserver.html)。这只限制同用户连接，不是对恶意同用户进程的完整防御。

UTF-8 JSON 每行一帧；每帧最多 32 KiB，分片缓存有上限。首帧必须 hello，包含 protocolVersion=1、准确 pluginId 与本次 token。未握手不得发布活动；握手不重放；认证值不写日志。

宿主校验并重新生成插件来源命名空间，不接受 builtin 来源、宿主路由或任意代码。source 使用本地短名；路由由注册清单决定。持久活动优先级上限 60，短暂提醒上限 95；每插件最多 8 个来源，消息速率有界。字段只允许有限文本、图标、有限进度、展示类型；禁止原始命令、终端输出及可执行内容。插件自身仍有责任不在合法标题字段写入敏感内容，校验不能自动判断文本语义。

消息类型：hello、state、event、withdraw。事件必须有去重 key；持续状态和事件都必须主动声明 priority。退出/断开/停用撤回该插件所有来源，不能留下幽灵活动。宿主到插件的控制首版仅 show/close，不让插件代替用户执行系统操作。

## 后续验收门槛

1. 协议单元测试：分片/多帧、错误 JSON、超长、版本/token/ID 不匹配、未认证、越权字段、超限来源与洪泛。
2. 本地真实子进程测试：握手、断开、启动失败、故障后宿主存活、关闭回收；测试假插件不能执行系统命令。
3. 主应用无插件编译/运行/打包通过；MSIX 不含终端专属文件，插件包独立构建与部署。
4. 工具箱管理、可选包启动、原生 A/R/中文/Tab/焦点实测；需要人工条件时停止请求，不带着未确认问题合并或推送。

## 实施进度

已新增独立于具体插件的 PluginProtocol 解析/认证/消息校验，并通过单元测试。已新增 PluginProcess 通用生命周期实现，使用随机每次启动凭据、8 秒握手上限、2 秒退出回收、断开撤回来源及保留 Windows 用户环境；具体主应用接入与终端可选包拆分尚未完成。新增代码没有暴露宿主对象，协议单测不执行系统操作。消息来源命名空间采用插件 ID 的 SHA-256 前 16 个十六进制字符，避免长插件 ID 导致灵动岛 64 字符来源上限失效。

真实假插件子进程测试已通过：握手/状态/show/close、错误 token 拒绝、意外退出撤回来源及重启。测试子进程只是本测试程序，不运行终端、系统命令或改变设备。它证明通用适配基础可用，不证明终端已经拆分，更不证明任意第三方插件已安全隔离。

后续实施已完成源代码拆分与通用宿主接入：所有终端 C++/QML/Runner 位于可选插件目录；主目标不编译或依赖终端，主包不捆绑插件，工具箱改为独立窗口管理。API 清单升级 schema 2，包哈希、路径、额外文件、显式信任与版本校验已实现；真实终端 UI 进程握手/show/close 和真实部署包校验通过。新增 host→plugin theme 颜色数据消息、plugin→host closing 正常关闭消息；不向插件暴露核心 QObject。完整安装与人工门槛参见 0.8.2.0 候选记录，尚未完成全面验收。

构建：主应用默认 SIDEBAR_BUILD_TERMINAL_PLUGIN=OFF，独立插件可在其目录作为 CMake 项目配置；兼容的 SIDEBAR_BUILD_TERMINAL_TESTS 会配置可选项目以运行隔离测试，但主应用目标无终端依赖。打包脚本需要能部署 MSVC x64 CRT，未发现时必须提供 -MsvcRuntimeDir（主 CMake 打包目标可配置 SIDEBAR_MSVC_RUNTIME_DIR）；缺失即失败。独立包脚本 scripts/build-terminal-plugin.ps1 只写新的输出目录，不覆盖原包。
