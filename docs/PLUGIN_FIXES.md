# 插件与侧栏修复

- MSIX 构建显式包含 plugins 目录及 sidebar-terminal-runner.exe；缺少 Runner 时打包失败并给出路径。
- 插件注册器对缺失目录和无效清单提供具体错误信息，设置页可查看并重新扫描。
- 插件页面首次访问时加载，访问后保留实例，避免切换页面丢失输入历史；失败页面提供重试按钮。
- 收起后抑制悬停展开，鼠标离开后恢复自动展开，避免自动隐藏模式下手动收起立即被反转。
- 主监控页隐藏滚动条，保留滚动操作。

验证：Release 构建、QML 检查和打包脚本 PowerShell 语法检查。MSIX 安装后的交互行为仍需安装回归。
