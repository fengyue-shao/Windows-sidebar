# 0.8.1.1 主应用功能测试版

本地开发预览，不是远程正式发布。AI 层仍预定为插件。工具箱继续作为插件管理的唯一 GUI 入口；本次系统功能在主应用卡片中提供。

初次测试包为 0.8.1.0；Windows 拒绝同标识不同内容的覆盖安装（0x80073CFB），因此后续修订提升为 0.8.1.1，正常更新而非卸载，保留用户数据。

## 使用入口

从 Windows 开始菜单启动 Windows Sidebar，以获得 MSIX 包身份。顶部边缘停留或 `Ctrl+Alt+Space` 唤出精简栏，双击中间区域展开卡片。网络详情、移动热点、保持唤醒、USB 位于监控页；OCR 位于剪贴板页。

### 剪贴板图片 OCR

点击图片行的“识别文字”，读取对应 Windows 历史项的原图（不是缩略图），在本机使用 Windows OCR 识别。结果可编辑、选择及换行，点击“复制编辑后的文字”才写入剪贴板。点击识别、置顶或删除不会同时恢复原图；点击图片或文本内容恢复历史项。

要求 MSIX 包身份与系统已安装的 OCR 语言。使用用户语言配置中的可用识别器，不安装额外模型、不上传内容、不自动截图。一次只识别一张；图片上限 12 MB，并检查 Windows OCR 最大边长；结果最多 65536 字符。历史项已消失或权限不足时提示失败。识别中不能关闭结果区，以避免误认为操作已取消。

### 网络详情

点击“详情”展开活动的非回环适配器：名称、描述、IPv4/IPv6 和前缀、网关、DNS、MTU、链路速率。VPN/虚拟适配器也可能出现。概况和计费信息属于 Windows 默认互联网连接，不代表每个列出的适配器；链路速率不是实时吞吐量，互联网连接等级不是网站可达性保证。每 15 秒只读刷新，也可手动刷新；不主动探测外部服务器，不修改网络。

### 移动热点

使用 Windows 当前默认互联网连接共享，读取热点名称、状态和连接设备数。开关需二次确认；修改名称与密码时必须先关闭热点。名称限制 1–32 UTF-8 字节，密码限制 8–63 位可打印英文字符。密码输入隐藏，提交/取消/收起或离开后清空，不写入应用设置和日志；Windows 自己保存的热点配置仍由系统管理。

应用包声明 `wiFiControl`。硬件、系统策略、无线状态或上游网络可能使控制不可用；提供 Windows 热点设置兜底入口。不自动开启 Wi-Fi、不禁用系统的无客户端超时、不选择其他上游、不强制修改共享策略。真实开关测试尚未执行。

### 定时保持唤醒

可选 15/30/60/120/240 分钟，勾选项决定是否同时保持屏幕开启，点击开始后需确认。未勾选时只阻止系统自动睡眠，屏幕仍遵循系统策略。停止、到期、正常退出时调用 `SetThreadExecutionState(ES_CONTINUOUS)` 释放；释放失败保留活动状态并每秒重试。系统请求属于当前线程，不改注册表或电源计划。使用系统启动以来时间，避免改时钟影响；不会阻止用户主动睡眠，重启应用后不恢复请求。

用户指定本轮只使用模拟系统请求和时钟测试，未进行真实电源操作。异常结束时 Windows 会随线程终止撤销线程的执行状态请求。

### USB 安全弹出

只显示具有显式 removable 能力、服务为 USBSTOR/UASPStor 的物理 USB 存储函数；不以 USB 集线器或控制器为目标。检查磁盘总线、编号、系统卷映射和分区布局；系统磁盘、MBR 启动分区、GPT EFI 分区、无法读取或核验的磁盘排除。第一版要求至少有可见盘符；挂载文件夹、无盘符磁盘、未知硬件不保证显示。

同一个物理设备的多个卷合并展示，确认文字明确提示整个设备及全部卷都会断开。确认后重新枚举核验，再调用 `CM_Request_Device_EjectW`；不强制删除设备，不强制卸载文件系统，不关闭其他进程。系统拒绝时展示文件占用/应用/服务/驱动/权限等原因。成功是 Windows 接受安全移除请求，应确认设备消失后再拔出。

当前机器未发现可核验设备，因此仅验证枚举、目标过滤、16 种磁盘保护组合和未知 ID 拒绝，未执行真实弹出。

## 可复现测试

Release 构建沿用项目 CMake 配置。普通 EXE 测试：

```powershell
Start-Process '<构建目录>\Release\appqt_rainmeter.exe' -ArgumentList '--feature-self-test=<绝对日志路径>' -WindowStyle Hidden -Wait
./scripts/test-dropdown-ui.ps1 -Executable '<构建目录>\Release\appqt_rainmeter.exe' -CapturePath '<绝对截图路径>'
```

安装 MSIX 后测试真实包身份：

```powershell
./scripts/test-packaged-features.ps1 -LogPath '<全新的绝对日志路径>'
```

使用 COM 应用激活接口传参，而不是直接运行 WindowsApps 内的 EXE。OCR 使用内存中生成的 `WINDOWS OCR TEST 123` 图片，并走生产识别管线；不读私人历史、不覆盖剪贴板。测试只读取热点和网络、枚举 USB，唤醒调用为模拟接口。日志必须有 `FEATURE_TEST PASS`，UI 日志必须有 `UI_SELF_TEST PASS`；QML 错误、样式定制警告与无效截图尺寸均失败。

## 尚需人工验收

1. 自己选一张中文/英文历史图片，识别、编辑、复制，确认原图未被误恢复。
2. 对照 Windows 网络设置核对适配器和默认连接；尝试 VPN/断网后刷新。
3. 获明确许可后开启/关闭热点、保存配置，并用另一台设备连接；核对错误和流量提示。
4. 保持唤醒真实验证仅在用户另行许可后进行，本轮不执行。
5. 插入可测试的非系统 USB 存储，检查所有盘符，再确认安全弹出；另测文件占用时的系统拒绝。无硬件或未获许可时不要勾为通过。
