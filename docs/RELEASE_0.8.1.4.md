# Windows Sidebar 0.8.1.4 · 原生功能测试版

日期：2026-10-03。分支 codex-do；应用标识 0.8.1.4-preview，MSIX 0.8.1.4。已本地安装，未推送远程。

## 更新

- 通知按应用分组、搜索/仅未读，批量操作仅当前结果；系统确认后移除，关闭监听保留列表、重新开启同步。
- 输出设备切换失败提示及三种音频角色结果核验。
- Wi-Fi 连接事件与超时、适配器/原始 SSID 关联，断开/二次确认忘记，开放/WPA2 隐藏网络；其他安全类型引导系统设置。
- 蓝牙 30 秒动态发现窗口、即时新增/更新/移除、初始枚举对账、停止及过期事件隔离，配对忙状态/等待上限。
- OCR 30 秒、热点 45 秒等待上限与停止入口，嵌套取消传播、退出收尾、旧结果隔离。停止不保证 Windows 操作已撤回，不自动重试。
- 顶部栏快捷键自定义，冲突保留原值；默认关闭的全屏边缘抑制，不影响快捷键。
- USB 完整拒绝类型/返回码/关联对象提示及占用失败模拟回归，不绕过系统保护。

麦克风输入设备仍使用 Windows 设置入口。没有修改灵动岛、终端插件、插件平台或 AI 层；终端插件保留自身旧版本。

## 证据与限制

最终构建、10 项隔离测试、两组生产卡片离屏交互、包身份功能自检及完整 UI 自检通过。安装版蓝牙即时发现/窗口结束/手动停止、通知空状态、快捷键唤出及新增布局已屏幕观测。第一次完整 UI 自检超时未记为通过，45 秒明确上限的复测退出码 0、五张截图齐全，首次耗时原因尚未证实。

本机当前可核验 USB 为 0、通知为 0；真实 USB 弹出、通知删除、配对、断网/忘记、热点开关、多屏及长期稳定性尚需人工条件/明确授权。保持唤醒继续只模拟，不承诺所有硬件场景无 bug。
