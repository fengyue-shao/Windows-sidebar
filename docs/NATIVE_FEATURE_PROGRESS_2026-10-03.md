### 实现

- 模型的删除与清空入口只发出请求，不提前删行。Windows 移除事件或成功读取的系统快照才更新列表；异常保留未确认项目。
- 删除/清空 API 返回后重新读取系统列表，而不把“调用未抛异常”直接当作所有通知已消失。仍存在的待删除 ID 会显示尚未确认提示，不自动重试删除。
- 快照按 ID 去重、移除系统中已不存在的项，保留仍存在通知的本地已读状态。失败/权限撤销不应用空快照。
- 启动检查保存的模块开关；关闭使会话失效、撤销事件订阅，并尽力取消授权/读取操作。保留模型；再次开启建立新会话同步。取消是尽力请求，不代表 Windows 工作立刻撤回；旧结果不得影响新会话。
- 所有服务状态更新、事件触发后的系统读取以及模型更新均回到 Qt 主线程。异步回调携带独立会话与 QPointer，避免关闭后重新激活订阅。
- 同步期间收到事件会使旧快照失效并重新同步，避免旧数据复活已移除项。这里不会自动重复删除操作。
- 通知卡片新增独立状态区与刷新/重试，权限拒绝或错误不会显示成“已成功读取且没有通知”。同步/未就绪期间禁用删除与清空；全部已读仍是本地操作。
- 未改变灵动岛的展示、优先级、队列或通知事件连接；未修改插件。

## 当前任务 3：通知搜索、未读筛选与应用分组

### 实现与产品决定

- 新增独立 `NotificationViewModel`，只负责排序/筛选，不覆盖原系统列表。搜索为应用名称、标题、正文的不区分大小写文字子串匹配；空白输入不筛选，方括号等字符不作为正则表达式。
- 独立小卡片提供搜索框、“仅未读”、显示项计数和重置按钮；无结果提示与真正无通知/授权失败区分。
- Windows 通知采集保留 `AppUserModelId`。优先用该标识分组，缺失时退回系统提供的应用名称，无名称显示“未提供应用名称”，不推断语义。相同显示名但不同应用 ID 不合并；组内按时间倒序，时间相同按通知 ID 稳定排序，组间按分组键稳定排序。
- 单项操作解析当前通知 ID，不能把过滤后的第 N 行当源列表第 N 行。已读操作造成未读筛选即时变化时也不会误操作下一行。
- 用户明确选择批量操作“仅当前筛选结果”。按钮标注“当前项已读”“清空当前项”；点击时冻结 ID 列表，再执行操作。批量删除逐项调用 RemoveNotification，不调用 ClearNotifications；不受随后进入列表的新通知影响。
- 模型剔除不可删除、空 ID、重复或已失效的目标；部分系统删除失败会保留错误提示。API 后仍用系统快照/删除事件确认，不做乐观删行。

## 当前任务 4：Wi-Fi 生命周期、断开、忘记与隐藏网络

用户确认：隐藏网络只支持开放/WPA2，其他类型引导 Windows 设置；忘记当前连接必须二次确认后断开再忘记。另确认全屏抑制只做可选开关，默认不禁止边缘唤出。

实现：连接前注册 ACM 通知，持续持有句柄到完成/失败/30 秒等待超时。按操作代次、适配器、原始 SSID、配置名关联事件；单次 attempt_fail 不作为最终失败，complete 的 reason 决定结果。成功事件和超时都查询实际连接，查询未匹配不显示已确认。回调只复制固定数据并排队，关闭/注销在 Qt 线程执行，不从 WLAN 回调中注销。

网络条目保留原始 SSID、适配器、安全算法；UI 显式传适配器，不再跨适配器仅按 SSID 去重。配置使用原始 SSID 的 hex，不把企业/其他安全类型推测为 WPA2。不覆盖同名配置；现有配置继续由 Windows 处理安全类型，新建配置只开放或 WPA2PSK/AES，密码入口限 8–63 字符，其他格式回退系统设置。新增隐藏网络小表单与系统设置入口。

断开/忘记前重新核对当前适配器状态和配置，无法读取或正在改变状态时拒绝执行；不能断开无关网络。当前配置经断开事件/15 秒超时后的状态查询确认为 disconnected 才删除；没有确认不删除。非当前配置可单独忘记，不断开其他连接。UI 二次确认，长状态换行，忙时禁止重复操作。超时只停止本应用等待，不保证系统请求被取消。仍存在系统状态在核验后改变的竞态，不能承诺强事务性；统一安装后需真实适配器验证。
