# 0.8.0.2

本版本将 codex-do 上的插件系统、持续 Shell 终端和控制中心进度合并至 main。

## 终端稳定性

- 使用可取消的单次计时器，避免旧命令超时误杀后续命令。
- 运行中输入框保持焦点且只读，Ctrl+C / Esc 可传递至中止处理。
- `/reset` 终止 Runner，清空会话变量，恢复初始目录并清空显示与输入历史。
- 文件补全检查目录规范路径，拒绝沙盒目录之外的枚举。
- 候选面板完整展示八个补全项目。
- CMD 完成标记在下一行读取 errorlevel，避免同一行提前展开错误码。
- Job 资源限制配置失败时停止启动，避免以未应用限制的状态继续运行。
- 宿主析构时终止并等待 Runner。

## 发布范围与限制

应用版本、MSIX 清单版本、终端插件版本统一为 0.8.0.2。
ConPTY 目前仅检测系统 API 是否可用，尚未创建伪控制台，也没有 VT 屏幕渲染；完整交互式 TUI 留待后续版本。

Job Object 限制资源和进程生命周期，并不隔离文件系统或网络。宿主对单独 cd 命令和补全的路径检查不能约束所有 Shell 命令；子程序仍以当前用户权限运行。不要将此插件当作执行不可信代码的安全沙盒。

已验证 Release 构建、PowerShell 跨命令变量与中文输出、CMD 非零错误码。界面快捷键变更经过代码检查，尚未完成自动化桌面交互回归。
